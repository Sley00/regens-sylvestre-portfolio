# Regens Sylvestre Portfolio

A modern personal portfolio website built to showcase my projects, technical skills, professional experience, and background in Computer Science.

## Live Demo

https://regens-sylvestre-portfolio.vercel.app

## About the Project

This portfolio was built as a responsive web application to present my work and growing experience in software development.

The website includes:

- Personal introduction
- Projects
- Technical skills
- Professional experience
- Certifications
- About section
- Contact page

## Technologies Used

- Next.js
- React
- TypeScript
- JavaScript
- HTML
- CSS
- Tailwind CSS
- Git & GitHub
- Vercel

## Project Structure

- `src/app` — application pages and routes
- `src/components` — reusable interface components
- `src/data` — portfolio content and project data
- `public` — static assets

## What I Learned

Through this project, I practiced:

- Building reusable React components
- Creating responsive interfaces
- Working with Next.js routing
- Using TypeScript
- Organizing a web application
- Deploying a production website with Vercel
- Using Git and GitHub for version control
